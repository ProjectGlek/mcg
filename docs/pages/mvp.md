# План тестовой технодемки 

Первая версия MVP нужна для теста кор геймплея, и проверки работают ли механики Vampire Survivor вместе с милым сеттингом. 

MVP-1 должно включать в себя:

- Главного героя (или заглушку)
- Реализованный вариант мувмента и управления ГГ
- 3 типа врагов (или заглушки)
- Реализованный спавн врагов, баланс
- 3 разных скила с 3 вариантами прокачки(увеличение урона, ускорения снарядов и тд.)
- Базову версию стартовой локации или ее заглушку
  
По итогам сможем понять хорошо ли работает придуманная формула и сразу отредактировать ее, при потребности. Так же  было бы хорошо создать рабочие билды версии MVP-1 чтобы проверить на потенциальных игроках.
